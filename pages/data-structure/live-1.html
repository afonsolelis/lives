📦 Arrays (Vetores)

  • Coleção contígua na memória
  • Acesso por índice em O(1)
  • Tamanho fixo (em linguagens estáticas)
# Python
arr = [10, 20, 30, 40, 50]
print(arr[0])      # 10 (O(1))
print(arr[-1])     # 50 (O(1))
arr.append(60)     # O(1) amortizado
arr.insert(0, 5)   # O(n) - desloca elementos

Use quando: acesso aleatório frequente, tamanho conhecido

🔗 Listas Ligadas (Linked Lists)

  • Nós conectados por ponteiros
  • Inserção/remoção em O(1) (se tiver referência)
  • Acesso sequencial em O(n)
  • Não precisa de memória contígua
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

# Lista: 1 -> 2 -> 3 -> None
head = Node(1)
head.next = Node(2)
head.next.next = Node(3)

📚 Pilhas (Stacks)

LIFO - Last In, First Out

  • Inserção e remoção no topo
  • Operações: push, pop, peek
  • Todas em O(1)
stack = []
stack.append(1)    # push
stack.append(2)
stack.pop()        # pop → 2
stack[-1]          # peek → 1

Aplicações: undo/redo, call stack, DFS, validação de parênteses

🎫 Filas (Queues)

FIFO - First In, First Out

  • Inserção no final, remoção no início
  • Operações: enqueue, dequeue
from collections import deque
queue = deque()
queue.append(1)    # enqueue
queue.append(2)
queue.popleft()    # dequeue → 1
queue[0]           # front → 2

Aplicações: BFS, filas de impressão, task scheduling, buffering

🗂️ Hash Tables (Dicionários)

  • Mapeamento chave → valor
  • Acesso, inserção, remoção em O(1) médio
  • Usa função hash para calcular índice
  • Colisões tratadas com chaining ou open addressing
hash_map = {
    "nome": "João",
    "idade": 25,
    "cidade": "São Paulo"
}
print(hash_map["nome"])  # O(1) → "João"
hash_map["email"] = "joao@email.com"

🌳 Árvores (Trees)

  • Estrutura hierárquica
  • Raiz, nós internos, folhas
  • Árvore Binária: cada nó tem ≤ 2 filhos
  • BST: esquerda < nó < direita
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

#      5
#     / \
#    3   8
root = TreeNode(5)
root.left = TreeNode(3)
root.right = TreeNode(8)

🔄 Travessia em Árvores

DFS (Depth-First)
# Pre-order
def preorder(node):
    if node:
        print(node.value)
        preorder(node.left)
        preorder(node.right)
BFS (Breadth-First)
from collections import deque
def bfs(root):
    queue = deque([root])
    while queue:
        node = queue.popleft()
        print(node.value)
        if node.left: queue.append(node.left)
        if node.right: queue.append(node.right)

⛰️ Heaps (Pilhas de Prioridade)

  • Árvore binária quase completa
  • Min-Heap: pai ≤ filhos (raiz = menor)
  • Max-Heap: pai ≥ filhos (raiz = maior)
  • Inserção e remoção em O(log n)
import heapq
heap = []
heapq.heappush(heap, 3)
heapq.heappush(heap, 1)
heapq.heappush(heap, 2)
print(heapq.heappop(heap))  # 1 (menor elemento)

Aplicações: priority queues, Dijkstra, heap sort

🕸️ Grafos (Graphs)

  • Vértices (nós) + Arestas (conexões)
  • Direcionado vs Não-direcionado
  • Ponderado vs Não-ponderado
  • Representação: lista de adjacência ou matriz
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C']
}

Aplicações: redes sociais, rotas, dependências, recomendação

🎯 Guia de Escolha

  • Array: acesso por índice, dados contíguos
  • Lista: inserções/remoções frequentes
  • Pilha: LIFO, undo, DFS
  • Fila: FIFO, BFS, processamento em ordem
  • Hash: busca rápida por chave
  • Árvore: dados hierárquicos, busca ordenada
  • Heap: prioridade, k-ésimo elemento
  • Grafo: relações complexas, redes
