Por que importa?

Derivadas

Medem a sensibilidade do erro em relação aos pesos.

Parciais

Ajustam cada parâmetro da rede isoladamente.

Integrais

Calculam a área de erro total ou probabilidade.

Derivada: Taxa de Mudança

A reta amarela mostra como o valor muda a cada instante.

Derivada na Prática (IA)

No Gradiente Descendente, usamos a derivada para saber em qual direção "empurrar" o peso.

w_novo = w_atual - lr * (dL / dw)

Otimização

Se a derivada é positiva, o erro sobe com o peso. Então, diminuímos o peso para reduzir o erro.

Derivadas Parciais

Mudando uma variável e mantendo as outras fixas.

∂f/∂x
∂f/∂y
Gradiente (∇f) = [ ∂f/∂x, ∂f/∂y, ... ]

Integral: Acúmulo

A integral soma todas as pequenas variações para obter o total.

Implementação em Python


def derivative(f, x, h=0.0001):
    return (f(x + h) - f(x)) / h
